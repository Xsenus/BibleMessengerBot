# Руководство администратора

Администратор управляет рассылками и настройками бота. Владелец — первый администратор; он же назначает остальных. Всё, что делается в боте, можно делать и в [веб-панели](admin-panel.md).

| Разослать найденный стих | кнопка «📣 Отправить всем» | — | [broadcast.md](broadcast.md) |

| Следить за видеоканалами | `/video`, `/admin → Видео` | Видео | [video-watch.md](video-watch.md) |
| Подключить генераторы картинок (в том числе бесплатные) | — | Генераторы картинок | [image-providers.md](image-providers.md) |
| Назначить и снять администраторов | `/admin → Администраторы` | Администраторы | ниже |

Команда `/admin` открывает меню администратора в личном чате с ботом на любой платформе. Остальные документы раздела:

- [Веб-панель](admin-panel.md) · [Сеть и прокси](network.md) · [Профиль бота](branding.md) · [Добровольная поддержка](donations.md)

## Как назначить администратора

1. Владелец отправляет боту `/admin` и нажимает **«➕ Пригласить»** (или в панели: «Администраторы» → «Создать приглашение»).
2. Бот выдаёт одноразовый код, который действует 24 часа.
3. Новый администратор в **личном чате** с ботом (Telegram, MAX или ВКонтакте — где ему удобно) отправляет `/claim КОД`.
4. Готово: у него появляется `/admin`. Код сгорает после первого использования.

Снять права может только владелец: `/admin → Администраторы → Снять`. Владельца снять нельзя.

## Как пользоваться меню `/admin`

Меню — это кнопки, ничего вводить не нужно:

- **📣 Объявления** — список, пауза, возобновление, отмена. Создание — командой `/announce` или в панели.
- **📡 Источники** — включить или выключить источник, сменить режим (сохранять / с подтверждением / сразу).
- **🎬 Видео** — включить опрос канала и рассылку ссылок.
- **📊 Состояние** — активные чаты по платформам, очередь, доставки за сутки.
- **👥 Администраторы** — список, приглашения (владелец).

## Безопасность

- Все проверки прав выполняются при каждом нажатии: даже пересланная кнопка не сработает у обычного пользователя.
- Ключ панели `ADMIN_API_KEY` равноценен полному доступу: храните его только в `.env`, не публикуйте панель наружу без HTTPS и ограничения доступа.
- Ключи внешних сервисов, добавленные в панели, хранятся в базе зашифрованными и не показываются обратно ([подробно](image-providers.md#безопасность-ключей)).
