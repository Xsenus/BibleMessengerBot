# Telegram: команды, права и расписание

## Подключение назначения

Пользователь сначала открывает бота и отправляет `/start`. Бот не может начать личный диалог с произвольным пользователем. Для группы добавьте бота администратором; настройки меняет реальный администратор группы. Для канала боту нужны права администратора и публикации. Команды удалённого управления отправляются боту **лично** с последним аргументом `@channel` или отрицательным числовым ID.

При каждой команде и callback повторно проверяются права пользователя и бота. Анонимный администратор не считается достоверным отправителем: управляйте из личного чата. Владелец приложения, зарегистрированный через `/claim`, также не обходит права Telegram.

## Команды текущего чата

В личном чате `/start` показывает короткое приветствие с выбранным изданием и постоянную клавиатуру: «Читать дальше», «Стих дня», «Случайный стих», «Поиск», «Настройки», «Помощь». Кнопки запускают те же команды с обычной проверкой прав. Встроенные кнопки настроек остаются под соответствующими сообщениями. Обычный неизвестный текст в личном чате вызывает подсказку; произвольную переписку группы бот не превращает в команды.

Название, описания, аватар и список команд применяются фоновым модулем оформления. Свои изображения, поведение `/start` и ограничения интерфейса описаны в [BRANDING.md](BRANDING.md).

```text
/start
/menu
/help
/today
/random
/topics
/topic anxiety
/search слово или фраза
/claim ОДНОРАЗОВЫЙ_КОД
```

`/claim` допускается только в личном чате и использует секрет из `OWNER_CLAIM_CODE`. `/today`, `/random`, `/topic` и `/search` работают с выбранным изданием текущего чата; удалённый `target` для них не поддерживается. `/topics` выводит стабильные коды тем; их доступность для чтения зависит от нумерации выбранного издания.

`/menu` возвращает навигацию; `/search` без аргумента показывает пример поиска, а `/time` без аргументов — формат настройки времени с сохранённым часовым поясом. Сама кнопка «Поиск» не включает режим свободного диалога: отправьте `/search слово`.

## Управление текущим или удалённым назначением

`[target]` — необязательный последний аргумент: `@username` или отрицательный Telegram-ID. Без него используется текущий чат. Квадратные скобки обозначают необязательность, их вводить не нужно.

```text
/settings [target]
/register target
/language ru [target]
/ui en [target]
/translations [язык] [target]
/translation source:id [target]
/subscribe sequential 09:00 Europe/Moscow [target]
/subscribe verse 09:00 Europe/Moscow [target]
/subscribe topic 09:00 Europe/Moscow [target]
/subscribe reading_plan 09:00 Europe/Moscow bible-365 [target]
/time 08:30 Europe/Moscow [target]
/thread 123 [target]
/thread off [target]
/pause [mode] [target]
/resume [mode] [target]
/unsubscribe [mode] [target]
/next [target]
/license [target]
/status [target]
/reset confirm [target]
/resolve DELIVERY_ID sent [target]
/resolve DELIVERY_ID retry-duplicate-risk [target]
/resolve DELIVERY_ID cancel [target]
```

`/language` выбирает импортированное издание заданного языка и соответствующий поддерживаемый интерфейс. Если UI для языка отсутствует, сохраняется прежний интерфейс. `/ui` меняет только интерфейс; `/translation` выбирает точное издание. При неоднозначном коротком ID используйте полный `source:id` из `/translations`.

Режимы: `sequential`, `verse_of_day` (коротко `verse`), `topic_of_day` (`topic`), `reading_plan` (`plan`). Планы: `bible-90`, `bible-180`, `bible-365`, `new-testament-90`, `psalms-150`; доступность зависит от полноты выбранного текста. `/topic anxiety` запрашивает текущий отрывок темы и не устанавливает тему будущей рассылки.

`/reset confirm` сбрасывает прогресс назначения и ставит подписки на паузу; это явное изменение данных. `/unsubscribe` прекращает рассылку, но не удаляет аккаунт и историю.

## Два независимых канала

```text
/language ru @russian_channel
/ui ru @russian_channel
/subscribe sequential 08:00 Europe/Moscow @russian_channel
/language en @english_channel
/ui en @english_channel
/subscribe verse 09:00 Europe/Amsterdam @english_channel
```

Язык, издание, UI и расписание сохраняются для каждого назначения. Изменение одного канала не меняет другой. `/settings` показывает именно сохранённые настройки назначения. Выбор языка не скачивает корпус автоматически: нужное издание должен импортировать оператор.

## Прогресс и доставка

Для каждого чата допускается одна подписка каждого режима. Часовой пояс задаётся IANA-именем, учитываются переходы летнего времени. После простоя приложение не отправляет все пропущенные дни залпом. Планы считают дни успешного чтения: паузы увеличивают календарный срок.

`/next` ставит отрывок в очередь; прогресс продвигается после подтверждения всех частей. Ручное чтение хранит отдельный прогресс каждого издания. Смена издания сбрасывает расписанные планы на начало и останавливает несовместимые режимы; номера стихов не переносятся вслепую между разными системами нумерации.

`/pause` сохраняет подтверждённые части, `/resume` продолжает разрешённые задания. При `uncertain` сначала проверьте реальный чат, затем выберите `/resolve`: [разбор спорной доставки](OPERATIONS.md#неопределённая-доставка). Повтор после сетевой ошибки может дать дубль, поэтому автоматического обещания exactly-once нет.

Для форума на группу сохраняется одно назначение темы через `/thread`; отдельных наборов подписок на каждую тему нет. Потеря прав бота приостанавливает рассылку. При преобразовании группы в супергруппу старое назначение останавливается; новый ID необходимо зарегистрировать отдельно.

## Языки и атрибуция

В репозитории 24 каталога UI; их наличие не означает независимой вычитки носителями. Команды и идентификаторы источников не переводятся. Названия книг берутся из издания, затем из локального справочника, иначе используется код USFM. Текст Библии не переводится машиной.

В приветствии, настройках, списке переводов, статусе и под отрывком используются понятные названия изданий: «Синодальный перевод», «World English Bible». Для Public Domain/CC0 обычная подпись стиха или главы содержит название перевода. Полные сведения об источнике, лицензии и нумерации доступны через `/license [target]`; технические обозначения поясняются обычным языком. Для переводов, требующих атрибуции, в публикации сохраняются необходимые сведения о правах, авторстве, источнике и лицензии.

Короткая подпись меняет только отображение: исходные метаданные, `source:id`, координаты стихов, хеши и лицензионное решение сохраняются. При работе с CLI, отчётами и точным выбором `/translation` продолжайте использовать реальные идентификаторы изданий.
