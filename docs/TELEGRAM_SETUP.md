# Telegram: личные сообщения, группы и каналы

## Личные сообщения

Пользователь должен сам открыть бота и нажать Start. Telegram-бот не может
первым начать диалог с произвольным человеком.

```text
/start
/subscribe verse 09:00 Europe/Amsterdam
```

## Группа

1. Добавьте бота в группу.
2. Разрешите отправлять сообщения.
3. Администратор группы выполняет:

```text
/subscribe topic 09:00 Europe/Amsterdam
```

Обычный участник не может менять расписание группы.

## Канал

1. Добавьте бота в канал как администратора.
2. Разрешите публикацию сообщений.
3. В личном чате с ботом выполните:

```text
/channel @channel_name verse 09:00 Europe/Amsterdam
```

Команда проверит, что и пользователь, и бот являются администраторами канала,
зарегистрирует канал и создаст расписание.

## Смена перевода

Сначала выберите перевод в личном чате:

```text
/translations rus
/translation rus_synodal
```

После этого `/channel` назначит его каналу. Для существующей группы команда
`/translation ID` меняет перевод группы, если её вызывает администратор.

## Ограничения отправки

Worker применяет общий и поканальный rate limit, разбивает длинные главы на
несколько сообщений, обрабатывает Telegram RetryAfter, отключает подписку при
Forbidden и не отправляет один payload повторно благодаря уникальному ключу в
`delivery_log`.
