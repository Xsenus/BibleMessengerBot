# Краткий справочник команд

Команды вводятся в Telegram-чате с ботом. Квадратные скобки обозначают необязательный аргумент; вводить их не нужно. Подробное управление группами и каналами — [TELEGRAM_SETUP.md](TELEGRAM_SETUP.md).

## Чтение

| Команда | Действие |
|---|---|
| `/start` | Приветствие и основная клавиатура. |
| `/menu` | Вернуться к навигации. |
| `/help` | Справка и примеры. |
| `/next` | Следующая глава с сохранением прогресса после доставки. |
| `/today` | Стих дня. |
| `/random` | Случайный стих выбранного перевода. |
| `/search любовь` | Поиск слова или короткой фразы. |
| `/topics` | Список кодов тематических подборок. |
| `/topic anxiety` | Отрывок выбранной темы для совместимого издания. |
| `/license` | Подробности об источнике, лицензии и нумерации. |

Тематический режим доступен только для изданий с совместимой нумерацией. Поиск, стих дня и случайный стих работают в текущем чате.

## Настройки и рассылка

| Команда | Действие |
|---|---|
| `/settings [target]` | Настройки назначения. |
| `/language ru [target]` | Выбрать язык Библии и доступный интерфейс. |
| `/ui en [target]` | Изменить только язык интерфейса. |
| `/translations [язык] [target]` | Показать импортированные переводы. |
| `/translation source:id [target]` | Выбрать точное издание. |
| `/subscribe sequential 09:00 Europe/Moscow [target]` | Последовательное чтение по расписанию. |
| `/subscribe verse 09:00 Europe/Moscow [target]` | Ежедневный стих. |
| `/subscribe reading_plan 09:00 Europe/Moscow bible-365 [target]` | План чтения. |
| `/time 08:30 Europe/Moscow [target]` | Изменить время и часовой пояс. |
| `/status [target]` | Подписки, прогресс и незавершённые задания. |
| `/pause [mode] [target]` | Приостановить рассылку. |
| `/resume [mode] [target]` | Возобновить разрешённые задания. |
| `/unsubscribe [mode] [target]` | Прекратить рассылку выбранного режима или всех режимов. |

`target` — `@channel` или отрицательный ID. Удалённое управление отправляется боту лично от администратора назначения; у бота также должны быть необходимые права. `/register`, `/thread`, `/reset`, `/resolve` и `/claim` описаны в [полном руководстве](TELEGRAM_SETUP.md).

## Добровольная поддержка проекта

Эти команды доступны **только в личном чате**. Библия и функции бота остаются бесплатными; платёж разовый, без дополнительных прав или автоматического продления.

| Команда | Действие |
|---|---|
| `/donate` | Выбрать 25, 50, 100, 250 или 500 Stars. |
| `/donate 100` | Указать свою целую сумму от 1 до 2500 Stars. |
| `/donations` | История собственных платежей. |
| `/terms` | Условия добровольной поддержки. |
| `/paysupport` | Как обратиться по оплате. |
| `/paysupport Текст обращения` | Сохранить обращение оператору. |

Кнопка `⭐ Поддержать` открывает выбор суммы. Затем бот показывает условия и кнопку «Согласен, поддержать» перед созданием счёта. Платёж отдельно подтверждается пользователем в Telegram. `/donations` показывает до десяти своих операций с номером, суммой и статусом; `/paysupport` принимает обращение до 4000 символов, сохраняет его в БД и возвращает номер заявки. Рассмотрение выполняет оператор. Подробности и порядок возврата — [DONATIONS.md](DONATIONS.md).
