# Язык отдельного сообщения

Под каждым новым сообщением с библейским текстом есть кнопки доступных языков. Выбор заменяет текст в этом же сообщении. Иллюстрация сохраняется; если она ещё генерируется, её появление не сбрасывает выбранный язык. Новых сообщений, платных переводов и запросов генерации при переключении нет.

На странице показано до шести языков, по три в ряд. Стрелки ◀ / ▶ листают список по кругу, 🌐 показывает страницу, ✓ отмечает выбранный язык. Если переведённый текст превышает размер одного сообщения Telegram, появляется дополнительная строка 📖 для перелистывания текста в том же сообщении.

Кнопки доступны у случайного и ежедневного чтения, тематических и утренних/вечерних чтений, поиска по словам и адресу, целых глав, последовательного чтения и планов. У длинного результата каждая отправленная часть имеет собственные кнопки. Переключается отрывок этой части; если граница проходит внутри стиха, перевод показывает этот стих полностью. Служебные сообщения, меню и счета Stars не переводятся этими кнопками. Исторические сообщения до установки этой версии автоматически не меняются.

Список строится по импортированным активным изданиям с пройденной проверкой. Для каждого языка выбирается одно издание, покрывающее весь указанный адрес, с предпочтением исходного издания. Отсутствующие книги, главы и стихи исключаются. Используются сохранённые тексты БД, а не машинный перевод. Адреса соответствуют нумерации изданий; различия традиций нумерации между переводами автоматически не пересчитываются.

Выбор действует только на сообщение и сохраняется после перезапуска. Он не меняет язык чата, расписания, подписки, прогресс чтения или бюджет иллюстраций. В личном чате кнопками может пользоваться его владелец; в группах и каналах — администратор при наличии требуемых прав у бота. Проверяются настоящий чат, идентификатор исходного сообщения и сохранённая карточка.

## Хранение и доставка

Миграция `012_message_languages.sql` добавляет `reading_cards`: адреса отрывков, исходное и выбранное издание, исходный и текущий HTML, страницы списка/текста, связь с картинкой и подтверждённым сообщением Telegram. Секреты, произвольные входящие сообщения и ключи API в эту таблицу не записываются. Записи входят в штатную резервную копию PostgreSQL и удаляются при удалении чата из БД.

Редактирование проходит через постоянную SQL-очередь и блокировку чата. Перед отправкой читается последнее выбранное состояние карточки: запоздавшая задача не возвращает прежний язык. Потерянное подтверждение редактирования допускает повтор по тому же идентификатору сообщения; замещающих отправок нет. Окончательный отказ Telegram, например удалённое сообщение, фиксируется как ошибка. Поздняя иллюстрация использует эту же карточку и её текущий язык.

## Проверка

`tests/test_message_languages_postgres.py` использует отдельные одноразовые БД PostgreSQL и моделирует Telegram. Проверяются отправка и редактирование, перелистывание языков/текста, неполные издания, поздние картинки, порядок конкурирующих выборов, перезапуск очереди, защита чужих сообщений и все режимы публикации. Для выполнения SQL-тестов задайте `RUN_DB_TESTS=1` и `DATABASE_URL` тестового PostgreSQL с правом создания временных баз. Рабочая БД не очищается.
