# Панель администратора

Два способа управления: **меню в боте** (`/admin`, во всех мессенджерах) и **веб-панель на React** (`/panel/`).

## Меню в боте

`/admin` — объявления, источники, видеоканалы, состояние, администраторы (приглашения и снятие прав — только владелец).
Администратор любой платформы получает права по коду: владелец нажимает «Пригласить» → новый администратор отправляет боту `/claim КОД`.

## Веб-панель

Адрес: `http://127.0.0.1:8080/panel/` (порт `ADMIN_HOST_PORT`; наружу публикуйте только через HTTPS-прокси с ограничением доступа).
Вход по ключу `ADMIN_API_KEY` (не короче 24 символов); ключ хранится в `sessionStorage` вкладки и передаётся заголовком `X-Admin-Key`.

Разделы: состояние служб и очереди; объявления (создание с расписанием, картинка, аудитория, пауза/запуск); источники и их посты;
видеоканалы; администраторы. Все действия используют те же сервисы, что и бот.

REST: `/api/admin/*` (`overview`, `announcements`, `media`, `sources`, `posts`, `videos`, `admins`) — JSON, ключ в `X-Admin-Key`,
ответы без кэша, CSP `default-src 'self'`.

## Сборка

В Docker панель собирается автоматически (`node:22` → `app/web/static/panel`). Локально: `cd admin-ui && npm ci && npm run build`;
режим разработки: `npm run dev` (прокси на `127.0.0.1:8080`). Если каталог сборки отсутствует, `/panel` не подключается, остальное работает.

## Раздел поддержки

Скрыт переменной `SUPPORT_SECTION_ENABLED=false` (по умолчанию): нет кнопки в меню, команд `/donate` и `/paysupport`, текста в справке.
Платёжные обработчики (возвраты, уже начатые платежи) продолжают работать. Чтобы вернуть раздел: `SUPPORT_SECTION_ENABLED=true` и перезапуск.
