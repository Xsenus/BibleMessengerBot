# Источник, лицензии и полнота переводов

**В этой поставке нет ни одного загруженного полного издания.** Число56 относится к списку целевых языков импортёра. Число24 относится к включённым каталогам интерфейса. Их нельзя складывать или считать подтверждёнными переводами Библии.

Источник: BibleNLP/ebible, закреплённая ревизия `c531ff2da02843ded6d09afbe29a197ab844981f`. Каталог, лицензии, сетка ссылок и тексты берутся из одной ревизии, не из меняющейся ветки main. Обновление ревизии требует отдельной проверки/поставки, `--refresh` повторно скачивает тот же снимок.

Прежде чем скачать/импортировать редакцию, требуется явная совместимая лицензия и разрешение источника на скачивание/распространение. Допускаются Public Domain, CC0, CC BY, CC BY-SA. NC, ND, неизвестные/конфликтующие значения отклоняются. Настройки допуска неизвестных/ограниченных лицензий в этой поставке запрещены. Это технический фильтр метаданных, не самостоятельная юридическая экспертиза всех прав во всех странах. Лицензия кода MIT не заменяет лицензии текстов.

Для каждой загруженной редакции сохраняются название, источник, атрибуция/правообладатель, URL лицензии, SHA256 и измеренное покрытие. Публикации содержат сведения об издании; `/license` позволяет получить источник/лицензионную информацию. Не удаляйте атрибуцию у CC BY/BY-SA и проверяйте условия конкретной редакции перед переизданием или изменением текста.

Корпус BibleNLP содержит только текст стихов, без введений, комментариев и сносок. Нумерация нормализована к Original versification. Она может отличаться от привычной нумерации конкретного перевода, особенно в Псалтири. Нельзя использовать этот корпус как доказательство совпадения страниц/номеров печатного издания. Источник: https://github.com/BibleNLP/ebible#data-format (проверено21.09.2026).

Пустые строки источника — отсутствие текста; `<range>` — продолжение объединённого стиха. Их нельзя публиковать как стих или заменять текстом другого языка. Парсер сохраняет диапазоны и проверяет соответствие строк сетке. Выводит точный исходный текст с HTML-экранированием, без генерирования новых библейских фраз.

На сервере точный результат:

```bash
docker compose run --rm --no-deps bootstrap python -m app.cli audit
docker compose run --rm --no-deps bootstrap python -m app.cli stats
```

`runtime-evidence/database-audit.json` содержит реальные редакции/счётчики/пропуски. Если исходный файл недоступен, язык не записывается как загруженный. Техническая проверка структуры не является независимой построчной вычиткой или подтверждением полного православного состава книг.
