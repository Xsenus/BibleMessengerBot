# Переводы, языки и полнота

В 1.3.0 по умолчанию работает all-open: нет фиксированного лимита в 56 языков или двух редакций. Сканируются доступные каталоги BibleNLP/eBible, getBible и HelloAO. Для каждого кандидата отдельно проверяются права, скачивание и поддержка формата. Изданий, прошедших полный импорт в среде подготовки: **0**. Не следует считать план инвентаризации наполненной БД.

Профили core/extended сохранены как необязательные фильтры. Количество кодов профиля не равно числу реально доступных полных Библий. Частичный корпус и NT не выдаются за полную Библию; структурное 66-книжное ядро не подтверждает православный/католический состав, текстологическую точность или печатную нумерацию.

Список фактически импортированных редакций: /translations в Telegram, таблицы PostgreSQL, полный receipt и database-audit. ID source:id различают одноимённые записи сайтов. Имена книг берутся из конкретного издания при наличии; иначе fallback к готовому имени или USFM-коду, а не машинный перевод.

Лицензии: распознанные PD/CC0/CC BY/CC BY-SA, без неизвестных, NC, ND, конфликтующих или запрещённых условий. Иногда разрешённая редакция потребует ручного уточнения формата декларации: политика намеренно не угадывает. Запрещённые тексты не добавляются автоматически.

Чтение по порядку, случайный стих, стих дня и поиск применяются к самому выбранному изданию. Тематическая база 1.2.0 имеет номера BibleNLP; для getBible/HelloAO она не применяется без отдельной карты. Подробнее: MULTISOURCE_IMPORT_RU.md.
