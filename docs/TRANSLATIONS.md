# Переводы, языки и лицензии

## Источник

Импортёр использует метаданные и verse-per-line корпус `BibleNLP/ebible`,
полученный из публикаций eBible.org. Общий файл ссылок `vref.txt` сопоставляется
со строками каждого перевода. Пустая строка означает отсутствующий стих, а
`<range>` — продолжение диапазона стихов.

## Профили

### core — 25 языков

Английский, русский, украинский, испанский, французский, немецкий,
португальский, итальянский, нидерландский, польский, румынский, арабский,
турецкий, хинди, бенгальский, урду, тамильский, телугу, вьетнамский,
индонезийский, китайский мандарин, японский, корейский, суахили и библейский
иврит.

### extended — 56 языков

К `core` добавлены чешский, словацкий, венгерский, болгарский, сербский,
хорватский, словенский, шведский, норвежский, датский, финский, современный и
древнегреческий, персидский, панджаби, гуджарати, маратхи, малаялам, каннада,
тайский, малайский, кантонский, амхарский, сомали, хауса, йоруба, игбо, зулу,
африкаанс, тагальский и латынь.

Наличие разрешённой полной редакции проверяется при каждом импорте. Язык может
быть пропущен, если на текущий момент нет редакции, одновременно являющейся
скачиваемой, перераспространяемой и подходящей под строгую лицензионную политику.

### all-open

Импортируются все редакции всех языков, которые прошли фильтр. Ограничение
`MAX_EDITIONS_PER_LANGUAGE` для этого профиля не применяется.

## Правила выбора

Для `core` и `extended` по умолчанию выбираются до двух редакций на язык:

1. явный приоритет известного открытого перевода;
2. полный Ветхий и Новый Завет;
3. большее число стихов;
4. отметка upstream Certified;
5. стабильный ID как последний критерий.

Это технический выбор по лицензии и полноте, не богословский рейтинг.

## Разрешённые лицензии

- Public Domain;
- CC0;
- CC BY;
- CC BY-SA.

По умолчанию запрещены:

- CC BY-NC и любые NonCommercial;
- CC BY-ND и любые NoDerivatives;
- All Rights Reserved;
- неизвестная лицензия;
- `Redistributable=False`;
- `downloadable=False`.

Параметры `ALLOW_RESTRICTED_LICENSES` и `ALLOW_UNKNOWN_LICENSES` существуют для
оператора с собственным юридическим основанием, но в поставке отключены.

## Что хранится для каждой редакции

- язык и направление письма;
- upstream ID и название;
- описание и URL публикации;
- тип, версия и URL лицензии;
- правообладатель и годы;
- переводчик;
- URL исходного файла;
- дата upstream;
- SHA-256;
- заявленное и фактическое число книг и стихов;
- дата импорта.

## Обновление

```bash
docker compose run --rm bootstrap python -m app.cli import --refresh
```

Если SHA-256 не изменился, текст не перезаписывается. Если изменился, редакция
заменяется в одной транзакции.
