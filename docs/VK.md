# ВКонтакте: третий мессенджер

Бот работает в ВКонтакте теми же возможностями, что в Telegram и MAX: чтение, поиск, планы, стих дня, молитвы,
картинки, озвучка (аудиосообщения-вложения), рассылки администратора и объявления. Один корпус Библии, одна база.

## Подключение

1. Сообщество ВКонтакте → «Управление» → «Работа с API» → создать ключ с правами «сообщения», «фотографии», «документы», «стена».
2. «Сообщения» → включить сообщения сообщества и «возможности ботов»; в «Работе с API → Long Poll API» включать вручную не нужно —
   бот сам включает Long Poll и нужные события (`message_new`, `message_event`, `wall_post_new`, …).
3. В `.env`:
   ```
   VK_BOT_TOKEN=<ключ сообщества>
   VK_GROUP_ID=<числовой номер сообщества>
   VK_SERVICE_TOKEN=<необязательно: сервисный ключ приложения для слежения за видео VK>
   ```
4. Запуск: `docker compose --profile vk up -d`. Сервис `vkbot` держит единственный Long Poll-клиент (advisory lock) и пишет события
   в `vk_inbox` до обработки, поэтому события не теряются при перезапуске, а повторы отбрасываются.

## Особенности платформы

- Только обычный текст (HTML превращается в текст со ссылками), inline-клавиатура: до 6 рядов и 10 кнопок — лишние строки
  отбрасываются, кнопка озвучки сохраняется.
- Идентификаторы: беседы ≥ 2 000 000 000; внутренние идентификаторы бота хранятся в `platform_identities` и не пересекаются с Telegram/MAX.
- Номер сообщения — `conversation_message_id` (контрольная точка отправки и правки).
- Администратором можно стать и во ВКонтакте: `/claim КОД` (код создаёт владелец в `/admin`).
- Платёжные функции во ВКонтакте не предусмотрены; раздел поддержки скрыт на всех платформах (`SUPPORT_SECTION_ENABLED=false`).

> Реальный API ВКонтакте в среде разработки недоступен: клиент, разбор событий, клавиатуры, очередь и диспетчер проверены
> автотестами с имитацией ответов. Перед запуском выполните пробное сообщение боту и проверьте `docker compose logs vkbot`.
