# С чего начать

1. Проверьте, [какой сервер нужен](vps-requirements.md).
2. Пройдите [быстрый старт](quick-start.md): от пустого VPS до работающего бота за несколько команд.
3. Нужны подробности и ручная установка — [полная установка](install.md).
4. Подключите нужные мессенджеры: [Telegram](../platforms/telegram.md), [MAX](../platforms/max.md), [ВКонтакте](../platforms/vk.md).
5. Станьте владельцем (`/claim`) и откройте [руководство администратора](../admin/README.md).
