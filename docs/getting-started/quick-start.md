# Быстрый старт

Что понадобится: VPS с Ubuntu или Debian (минимальные требования — [здесь](vps-requirements.md)), доступ по SSH с правами `sudo` и токен бота хотя бы одной платформы.

## 1. Токены

| Платформа | Где взять | Что записать в `.env` |
|---|---|---|
| Telegram | `@BotFather` → `/newbot` | `BOT_TOKEN` |
| MAX | кабинет MAX для бизнеса, после модерации бота | `MAX_BOT_TOKEN`, `MAX_WEBHOOK_SECRET`, `MAX_WEBHOOK_URL` ([подробно](../platforms/max.md)) |
| ВКонтакте | сообщество → «Управление» → «Работа с API» → ключ | `VK_BOT_TOKEN`, `VK_GROUP_ID` ([подробно](../platforms/vk.md)) |

Достаточно одной платформы: остальные подключаются позже.

## 2. Установка

```bash
sudo mkdir -p /opt && cd /opt
sudo git clone https://github.com/Xsenus/BibleMessengerBot.git bible-messenger-bot
cd bible-messenger-bot
sudo bash install.sh
```

Установщик спросит токен Telegram, создаст приватный `.env`, соберёт образ, прогонит тесты, применит миграции, импортирует тексты Библии и запустит службы. Чтобы не скачивать все издания, перед запуском скопируйте `.env.example` в `.env` и задайте ограничения по языкам ([install.md](install.md#настройка-перед-первым-запуском)).

## 3. Стать владельцем

Откройте бота в мессенджере и отправьте в личном чате:

```
/claim КОД
```

Код — значение `OWNER_CLAIM_CODE` из `.env`. Он одноразовый: после первого использования владелец назначен. Остальных администраторов приглашает владелец ([как](../admin/README.md#как-назначить-администратора)).

## 4. Включить дополнительные платформы

```bash
# ВКонтакте
docker compose --profile vk up -d
# MAX (нужен HTTPS-адрес для вебхука)
docker compose --profile max up -d
```

Каждый шаг описан в разделе [Платформы](../platforms/README.md).

## 5. Веб-панель

Панель слушает только `127.0.0.1:8080`. С компьютера откройте SSH-туннель и зайдите на `http://127.0.0.1:8080/panel/`:

```bash
ssh -L 8080:127.0.0.1:8080 user@ваш-сервер
```

Ключ входа — `ADMIN_API_KEY` из `.env`. Подробнее — [панель администратора](../admin/admin-panel.md).

## 6. Проверка

| Что проверить | Как |
|---|---|
| Службы работают | `docker compose ps` — все `healthy` |
| Бот отвечает | `/start` в личном чате |
| Тексты загружены | `/read Ин 3:16` |
| Панель открывается | `/panel/` через туннель, вход по ключу |
| Резервные копии | [Резервное копирование](../operations/operations.md#резервное-копирование) |

Если что-то не работает — [диагностика](../operations/troubleshooting.md).
