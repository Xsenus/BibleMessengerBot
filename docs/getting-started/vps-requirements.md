# Требования к VPS

Оценка по лимитам `docker-compose.yml`; это не измеренный SLA. Фактическое использование проверяйте через
`docker stats --no-stream`, `df -h`, `docker system df` и метрики из [monitoring.md](../operations/monitoring.md).

## Лимиты памяти по службам

| Служба | Лимит RAM | Когда нужна |
|---|---|---|
| `postgres` | 1 ГБ | всегда |
| `bot`, `worker` | по 512 МБ | всегда |
| `admin`, `composer` | по 256 МБ | всегда |
| `illustrator` | 384 МБ | картинки |
| `speaker` | 1,5 ГБ | озвучка (нейроголоса) |
| `max-web` + `maxbot` | 256 + 384 МБ | профиль `max` |
| `prayer-ai` | 1,25 ГБ | профиль `prayers` (локальный Qwen3) |
| `bootstrap` | 1 ГБ | только разовый импорт/миграции |
| `alerts`, `housekeeping`, `backup` | 128–256 МБ | одноразово, профиль `maintenance` |

Сумма постоянных служб без MAX и `prayer-ai` — около 4,4 ГБ лимитов; реальное потребление обычно ниже.

## Рекомендуемые размеры

| Профиль | Состав | CPU / RAM / диск |
|---|---|---|
| Минимум | Telegram, 2–3 языка, без озвучки и `prayer-ai` | 2 vCPU / 2 ГБ + 2 ГБ swap / 30 ГБ SSD |
| Рекомендуемый | озвучка, картинки, MAX; без `prayer-ai` | 2–4 vCPU / 4–6 ГБ / 60–80 ГБ SSD |
| Максимум | всё включено, импорт `all-open` | 4 vCPU / 8 ГБ / 100+ ГБ SSD |

## Что определяет диск

- Docker-образ с PyTorch и нейроголосами — несколько ГБ.
- Кэш источников — лимит по умолчанию 30 ГиБ; сократите, импортируя нужные издания, а не `all-open`.
- PostgreSQL растёт с числом изданий и историей доставок; [housekeeping](../operations/monitoring.md#хранение-данных-retention) ограничивает рост служебных таблиц.
- Локальные резервные копии: храните основные копии в [S3](../operations/s3-backup.md), а не на том же диске.

## Сеть

Для Telegram (long polling) домен и входящие порты не нужны. Для MAX требуется публичный HTTPS-адрес вебхука: [MAX_HTTPS](../platforms/max-https.md).
Картинки генерируют внешние API — вычислительные ресурсы сервера для них не нужны.
