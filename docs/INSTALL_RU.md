# Установка и переход на 1.3.0

Новая установка: `sudo bash install.sh` из распакованной папки. Нужны Ubuntu/Debian, интернет и токен BotFather. Домены и входящие публичные порты для polling-бота не требуются. Web-панель привязана к 127.0.0.1; используйте SSH-туннель, не открывайте её в интернет без собственного защищённого reverse proxy.

Установщик создаёт .env/секреты только при новой установке. При обнаружении существующего тома без .env останавливается: восстановите настоящий конфиг. На уже настроенном сервере перенесите старый .env в новый проект и используйте `sudo bash fill_database.sh`; тома PostgreSQL и кэша имеют прежние имена Compose-проекта.

Новый профиль — all-open, три источника. Старый .env не переписывается. Установка требует структурно полных русской и английской редакций по REQUIRED_LANGUAGES; если их получить не удалось, бот не запускается. Проблемы других источников могут дать частичный результат и доступны в отчёте. Установка не превращает его во «все Библии получены».

Подробные команды, фильтры, диагностика и границы: [MULTISOURCE_IMPORT_RU.md](MULTISOURCE_IMPORT_RU.md). Не выполняйте `docker compose down -v`. Сохраняйте секреты и backups вне публичных архивов.

Приёмка на вашем VPS ещё нужна: installer запускает установленные библиотечные тесты и временную PostgreSQL-БД, затем настоящие миграции/импорт/аудит. Эти процедуры не выполнены в среде подготовки. Если тесты или аудит не прошли, разберите ошибку; не обходите проверку принудительным стартом worker.
