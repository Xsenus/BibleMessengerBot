# Аудит исходной1.1.0 и изменения1.2.0

База: реально переданные ZIP/Git bundle; контрольная сумма ZIP: `3c9c6abeaacc3f4e93a57c42923c3621539ecbe0c98ed3175ff8dc8bc5045ccb`, commit `ac6045ed54c0aa814538dbaeeb3d12022b2eed94`. Доказательство совпадения файлов — `evidence/BASELINE-ARCHIVE.json`.

| Область | Найдено/ограничение прежней версии | Изменение |
|---|---|---|
| Поставка текстов | Нет вложенных Библий, профиль языка выдавался за потенциальное число редакций | Явное разделение target/imported/UI, обязательный фактический аудит БД |
| Язык | Основной интерфейс русский, изменение издания не обновляло все подписки |24 каталога, отдельные UI/content настройки назначения, revision и обновление подписок |
| Полнота | Метаданные источника недостаточны для вывода о фактической полноте |Измерение книг/глав/строк, NT/OT/partial/структура66, отсутствие выдуманных стихов |
| Диапазоны |Служебное продолжение не должно становиться самостоятельной цитатой |Строгий разбор диапазонов, verse_end, невидимые маркеры, валидная ссылка |
| Источник |Опасность смешения ревизий/редакций и неограниченной загрузки |Одна закреплённая ревизия, точные имена файлов, хеши, ограниченный потоковый кеш |
| Лицензии |Нельзя выводить CC BY из случайного слова by |Нормализованный fail-closed фильтр, конфликтующие/неизвестные права запрещены |
| Планы |90/180/365 не означали реального распределения всего чтения |Точное разбиение реального индекса глав на дни успешного чтения |
| Доставка |При повторе возможно повторить подтверждённые части; прогресс должен зависеть от подтверждения |Неизменный payload, чекпоинт каждого фрагмента, транзакционное завершение прогресса |
| Неопределённые сбои |Нельзя доказать недоставку по одному тайм-ауту |uncertain, остановка автоматического повтора, ручное решение с журналом |
| Группа/канал |Нельзя доверять регистрации вместо актуальных прав |Проверка администратора и права публикации при командах/callback |
| Время |Локальное время/переходы DST и пропущенные дни требуют явной политики |Валидация IANA, DST-тесты, без лавины пропущенных публикаций |
| Развёртывание |Нельзя объявлять успех без реальных SQL/импорта |Прогон интеграций на VPS, bootstrap/audit gate, сохранение .env, maintenance guard |
| Отчёты |Старые31 тест не подтверждают Telegram/SQL/полный корпус |Разделённые офлайн, skipped и runtime проверки; все результаты в архиве |

Список — отчёт о проведённой переработке, не утверждение об исчерпывающем отсутствии других ошибок. Полный запуск всё ещё подлежит приёмке на VPS.
