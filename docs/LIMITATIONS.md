# Проверенные ограничения

- В архив не встроены гигабайты текстов: они автоматически скачиваются и
  записываются в PostgreSQL на первом запуске. Это сохраняет актуальность
  upstream-лицензий и уменьшает размер поставки.
- Для первого запуска VPS нужен исходящий доступ к GitHub/eBible.
- Современные коммерческие переводы без отдельного разрешения не включаются.
- Точная доступность языков зависит от текущего upstream-каталога и лицензий.
- `core` и `extended` выбирают редакции технически — по лицензии и полноте, а
  не по конфессиональной или переводческой оценке.
- Диапазон стихов в upstream хранится текстом в первом стихе, остальные строки
  помечены как `<range>`; бот не дублирует один текст несколько раз.
- Код проверен статически и unit-тестами в среде сборки. Реальный Telegram API,
  Docker и PostgreSQL нельзя проверить без токена и внешнего VPS; это должны
  подтвердить `install.sh` и `diagnose.sh` на целевом сервере.
