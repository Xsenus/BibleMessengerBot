# Иллюстрации полных глав — 1.8.0

Кнопка «Читать дальше», `/next`, точный адрес целой главы через `/read`, `/search` или личный текст, а также последовательная подписка подготавливают **одну иллюстрацию главы**. Несколько глав одного дня в режиме плана чтения пока сохраняют прежнюю текстовую доставку.

Текст главы доступен сразу. Картинка из кэша входит в первую карточку; новая добавляется **редактированием первой карточки**, без уведомления об очереди и отдельного продолжения. Если вся глава помещается в прикладной предел Rich Messages (24 000 байт UTF-8), это одно сообщение. Более длинный текст делится безопасно: первая карточка редактируема, остальные части содержат весь оставшийся текст без повторных картинок. Подтверждённые части не повторяются; прогресс переходит к следующей главе только после подтверждения всех частей.

Prompt v3 содержит весь видимый текст главы выбранного издания, номера и диапазоны. Генератор выбирает одну основную сцену или смысловой образ, учитывая всю главу; для родословия предлагается образ поколений и преемственности. Выдуманные подписи, имена, схемы и события запрещены в задании. Качество интерпретации модели всё равно требует оценки человеком.

Кэш главы отделён от картинок отдельных стихов: `artwork_scope=chapter`, издание, книга/глава и SHA-256 полного видимого текста с координатами. Хеш имеет отдельный префикс области. Изменение любого видимого стиха или диапазона меняет идентичность; перед генерацией и редактированием проверяется полный источник. Уже оплаченная картинка отдельного стиха не выдаётся как новая иллюстрация всей главы. Один платный job объединяет повторные обращения; три календарных месяца, чередование архива и сохранение старых версий действуют как прежде.

Бюджет общий для глав и стихов: **GPT Image 2 medium, 10 API-попыток в UTC-сутки, $10 внутреннего резерва в месяц**. При исчерпании лимита текст остаётся доступен; ожидание редактирования ограничено 24 часами. Лимит не увеличен добавлением глав.

## Обновление

Сделайте backup, остановите `bot worker admin illustrator`, примените миграцию `009_chapter_artwork.sql`, запустите новую версию всех процессов. Миграция добавляет только область иллюстрации с `verse` для существующих записей, не заменяя картинки, их возраст, ID, задания и историю отправок. S3-манифест содержит `artwork_scope`; полный dump сохраняет всю схему и бинарные данные.

CLI поддерживает главу:

```bash
python -m app.illustrations_admin add --translation getbible:synodal --book GEN --chapter 5 --scope chapter --file /private/genesis-5.jpg
```

Для стиха сохранён прежний синтаксис с `--verse`. Экспорт заданий проверяет полный текущий источник и включает главы. Нужен клиент Telegram с поддержкой Rich Messages. Старые главы автоматически массово не переоформляются.
