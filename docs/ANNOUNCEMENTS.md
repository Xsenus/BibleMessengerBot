# Объявления и расписания

Администратор (любой платформы) публикует сообщение всем пользователям — разово или по расписанию.

## Из бота

```
/announce <когда> | Заголовок | Текст
/announce list
/announce pause|resume|delete|run ID
```

| Когда | Пример | Смысл |
|---|---|---|
| `now` | `now` | сразу |
| `once` | `once 2026-10-20 18:00` | один раз |
| `daily` | `daily 09:00` | каждый день |
| `weekly` | `weekly sat 10:00`, `weekly sat,sun 10:00`, `weekly weekdays 08:30` | по дням недели |
| `monthly` | `monthly 15 10:00` | раз в месяц (если дня нет, берётся последний день месяца) |
| `every` | `every 90m`, `every 2h from 2026-10-20 18:00` | через интервал (не реже 5 минут) |

Дополнения: `x5` — не более 5 запусков; `until 2026-12-31` — по дату включительно; часовой пояс IANA (`Europe/Moscow`) —
иначе берётся пояс вашего чата. Пример: `/announce weekly sat 10:00 Europe/Moscow x8 | Собрание | Ждём вас в субботу в 10:00!`

Меню `/admin` → «Объявления» показывает список с кнопками «пауза», «возобновить», «отмена», «сейчас».
Картинку к объявлению можно приложить в веб-панели (см. [ADMIN_PANEL](ADMIN_PANEL.md)).

## Надёжность

- Службу запуска (`composer`) выполняет один экземпляр; запуск идемпотентен: `UNIQUE(announcement_id, scheduled_for)`
  и ключ доставки `announcement:<запуск>`, поэтому перезапуск или повтор не дублирует сообщения.
- Опоздавший запуск (служба была остановлена) старше `misfire_grace_minutes` (60) **пропускается** и записывается как
  `skipped_late` — старые объявления не высылаются пачкой после простоя.
- Паузa и возобновление пересчитывают следующий запуск от текущего момента; пропущенное не догоняется.
- Доставка идёт через общую очередь `delivery_log` (режим `announcement`), не отменяется при смене настроек чата.
- Метрики `bible_announcements_active` / `bible_announcements_overdue`, оповещение при опоздании больше 15 минут.

Таблицы: `announcements`, `announcement_runs`, `media_assets` (миграция 028).
