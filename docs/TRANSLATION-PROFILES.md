# Профили импорта

`core`:25 целевых языков. `extended`:56 целевых языков. `all-open`:все подходящие открытые редакции всех языков в закреплённом каталоге. `none`:не импортировать, только диагностический запуск. Лимит `MAX_EDITIONS_PER_LANGUAGE` применяется к core/extended; all-open не следует рассматривать как ограниченные112 изданий.

По умолчанию extended и2 редакции на язык; это верхний предел выбора для профиля, не число скачанных или гарантированно доступных редакций. Полная языковая матрица находится в LANGUAGE-MATRIX.md. Приоритет отдаётся подходящему полному изданию, но итоговая структурная полнота вычисляется после импорта, не из предпочтительного имени.

`REQUIRED_LANGUAGES=rus,eng` задаёт минимальную готовность для обычного старта. Установщик откажется запускать сервис, если не сможет подтвердить структурно полный корпус обязательных языков. Отсутствующие необязательные языки остаются видимыми в отчёте. Поиск в остальных языках не переключается молча на русский.

Источники ограничены открытой лицензией/разрешением распространения и одной закреплённой ревизией. Исторический ID, наличие предпочтительного имени или целевого языка в JSON не доказывает наличие разрешённого текста в каталоге. На сервере выполняйте `python -m app.cli audit` из bootstrap-контейнера для фактических сведений.
