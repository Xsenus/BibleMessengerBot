# Профили импорта

`all-open` — по умолчанию: все языки/редакции, которые удалось обнаружить в выбранных трёх ресурсах и которые прошли политику/разбор. Лимит MAX_EDITIONS_PER_LANGUAGE игнорируется. Это не утверждение о наличии всех мировых переводов и не обещание полного текста на каждом языке.

`core` — прежний сокращённый набор кодов из data/language_profiles.json.
`extended` — прежние 56 целевых кодов; их число не равно реально импортированным языкам.
`none` — без скачивания.

Для core/extended лимит успешных редакций действует отдельно в каждом ресурсе на язык. `--languages` и `--editions` — дополнительные фильтры. Правило отбора не подменяет фактический отчёт: изучайте receipt и database-audit. На старой установке .env сохраняется; fill_database.sh без аргументов явно выбирает all-open.

Полный справочник переменных: [CONFIGURATION.md](CONFIGURATION.md). Проверенный набор конкретного развёртывания: [VALIDATION.md](VALIDATION.md).
