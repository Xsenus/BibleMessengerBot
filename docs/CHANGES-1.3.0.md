# Изменения 1.3.0

> Историческое описание соответствующей поставки. Актуальные изменения: [CHANGELOG](../CHANGELOG.md); текущие проверки: [VALIDATION](VALIDATION.md).

Продолжение Git v1.2.0 (0bf2284); подлинный входной ZIP SHA-256 c17fc2eb5be9361e94731f1999a7f3c271d32e5735adef0c155d342037102f54.

Добавлены три адаптера, строгий downloader с докачкой/лимитами/хешами, индивидуальная проверка лицензий, транзакционное сохранение и aliases, содержательные хеши и родные названия книг, JSON receipts, CLI discover/download/import/status/config, скрипт безопасного обслуживания fill_database.sh.

Bootstrap и прежний run_import подключены к новому runner; новая установка выбирает all-open. Старые credentials и пользовательские данные сохраняются. Старые SQL не изменены; новая схема добавляется миграцией003. Меню языков получило пагинацию. Для чужой нумерации запрещены непроверенные тематические ссылки.

Проверки включают synthetic HTTP, истечение/обрыв загрузки, Range/ETag, duplicate JSON keys, конфликтующие лицензии, неполный каталог/текст, изоляцию ошибок ресурсов, повторные импорты/удержание обновлений, блокировки и shell-порядок backup/import/audit/resume. Реальные дополнительные PostgreSQL/aiogram тесты написаны, но в среде сборки пропущены из-за отсутствия компонентов. Точные результаты исходной поставки — [исторический RELEASE-AUDIT](history/1.3.0/RELEASE-AUDIT.md) и соседний каталог `evidence/`.

Полного корпуса/дампа в поставке нет; скачивание и применение настоящих данных должны выполняться на VPS. Исторические отчёты 1.2.0 перенесены в docs/history/1.2.0 и не являются текущими результатами.
