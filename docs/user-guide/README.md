# Руководство пользователя

Бот читает Библию в Telegram, MAX и ВКонтакте одинаково. Все примеры подходят для любого из мессенджеров; отличается только оформление кнопок.

## Начало

Откройте бота и нажмите «Начать» (или отправьте `/start`). Появятся кнопки:

| Кнопка | Что делает |
|---|---|
| 📖 Читать дальше | Следующая глава; бот запоминает, где вы остановились |
| 🌅 Стих дня | Стих на сегодня |
| 🎲 Случайный стих | Случайный стих выбранного перевода |
| 🔔 Стих каждый день | Включает ежедневную рассылку |
| ⚙️ Настройки | Перевод, язык, время и часовой пояс |
| 🙏 Молитвослов | Подборки отрывков Библии для молитвы вслух (см. ниже) |

## Читать и искать

| Что нужно | Что отправить |
|---|---|
| Конкретный стих | `Ин 3:16` или `/read Ин 3:16` |
| Целая глава | `Пс 22` |
| Диапазон | `1 Кор 13:4–8` |
| Найти слово или фразу | `/search любовь` |
| Подборка по теме | `/topics`, затем `/topic anxiety` |

Адрес можно написать просто сообщением — команда не нужна. Если стиха нет в выбранном издании, бот так и скажет и не подставит другой.

## Язык и перевод

- Под каждым сообщением есть кнопки языков: нажмите — текст заменится в том же сообщении.
- `/language ru` — язык Библии, `/ui en` — язык интерфейса, `/translations` — список изданий.
- Древнееврейский Ветхий Завет — `/language hbo`, древнегреческий Новый Завет — `/language grc`.

## Ежедневное чтение

| Команда | Действие |
|---|---|
| `/daily 08:30 Europe/Moscow` | Стих каждый день в 08:30 |
| `/devotions` | Утренний и вечерний стих |
| `/time 07:00 Asia/Novosibirsk` | Изменить время и пояс |
| `/timezone` | Выбрать город — пояс подставится сам |
| `/pause` · `/resume` | Приостановить и продолжить рассылку |
| `/status` | Подписки и прогресс |

Выключить: `/daily off`, `/unsubscribe`.

## Картинки и озвучка

К стихам прикладывается иллюстрация, если она готова. Кнопка озвучки присылает аудио выбранного языка; для русского можно выбрать голос: `/voice david` или `/voice mary`.

## Группы и каналы

Бот можно добавить в группу или канал (в канале — администратором с правом публикации). Настройки у каждого чата свои. Управлять ими нужно **администратору группы или канала**, лучше из личного чата с ботом: добавьте в команду адрес назначения, например `/daily 09:00 Europe/Moscow @mychannel`. Подробности — [Telegram](../platforms/telegram.md).

## Если что-то не так

| Проблема | Что сделать |
|---|---|
| Бот молчит | Проверьте, что вы не заблокировали его; отправьте `/start` |
| Не пришла рассылка | `/status`: проверьте время, пояс и паузу |
| Нет нужного перевода | `/translations` показывает только загруженные издания |
| Картинки нет | Она может создаваться отдельно; текст приходит сразу |

Все команды — [справочник](../reference/commands.md). Условия добровольной поддержки проекта (когда раздел открыт) — [donations](../admin/donations.md).


## Молитвослов

Кнопка «🙏 Молитвослов» (или `/prayerbook`) открывает список молитв; нажмите нужную — бот пришлёт отрывки Библии **в вашем издании и языке**:

| Молитва | Отрывки |
|---|---|
| 🕊 О прощении грехов | Ин 3:16 и молитва покаяния |
| 🙏 Отче наш | Мф 6:9–13 |
| 💚 Об исцелении | Пс 6, Ис 53:4–6, Пс 102 |
| 👨‍👩‍👧 За семью и детей | Пс 1, 100, 127 |
| 🌾 О благополучии и достатке | Пс 22, 111 |
| 🛡 О мире и защите | Пс 90 |
| 📜 10 заповедей | Исх 20:2–17 |

Номера псалмов даны по синодальной нумерации; в изданиях с другой нумерацией бот сам подставляет нужный псалом. Если какого-то отрывка нет в вашем издании (например, в издании только Нового Завета), он пропускается. Закладки и серия чтения: `/bookmark`, `/bookmarks`, `/streak` (см. [команды](../reference/commands.md)).
