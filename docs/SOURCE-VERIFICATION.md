# Границы проверки внешних источников

Дата этой редакции:21.09.2026. Исходный архив1.1.0 и его Git bundle доступны локально и проверены на совпадение. Корпус из архива отсутствует. Прямые загрузки из контейнера, установка отсутствующих пакетов и скачивание eBible здесь завершились сетевыми ошибками; ни один полный корпус не импортирован и не подтверждён как проверенный.

Через web/GitHub прочитаны описание формата и отдельные заголовки/строки закреплённых файлов `metadata/translations.csv`, `metadata/licences.tsv`, `metadata/vref.txt`. Это подтверждает контракт формата и существование ревизии, **но не скачивание всей Библии**. Исторические примеры из1.1.0 не заменяют повторный импорт.

Первичные источники:
- https://github.com/BibleNLP/ebible — условия отдельных редакций, нормализованная сетка, пустые строки, диапазоны.
- https://github.com/BibleNLP/ebible/tree/c531ff2da02843ded6d09afbe29a197ab844981f/metadata — закреплённые метаданные.
- https://core.telegram.org/bots/faq — ограничения частоты, long polling/webhook.
- https://core.telegram.org/bots/api — контракты сообщений и прав.
- https://docs.aiogram.dev/en/latest/ — документация aiogram3.31.0 на дату проверки.

Офлайн-тесты HTTP-кеша используют httpx.MockTransport и синтетические данные. Интеграционные тесты SQL используют явно помеченный искусственный корпус в отдельной временной БД. Ни те, ни другие не выдаются за проверку подлинности Писания. Реальное скачивание и сверка физических строк выполняются установщиком только на VPS с рабочей сетью.
