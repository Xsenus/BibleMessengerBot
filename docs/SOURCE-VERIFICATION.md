# Проверка источников и контрактов — 22 сентября 2026

Первичные страницы, использованные при разработке:

- BibleNLP/eBible: https://github.com/BibleNLP/ebible — VPL, общий vref, пустые строки и `<range>`, лицензии конкретных редакций.
- getBible/v2: https://github.com/getbible/v2/blob/master/README.md — полные JSON-переводы, каталог и список книг; https://api.getbible.net/v2/translations.json — поля каталога и distribution_license.
- HelloAO: https://bible.helloao.org/docs/reference/translations/simplified.html — полный complete.simple.json и структуры перевод/книги/главы/строковые стихи.
- eBible: https://ebible.org/find/show.php?id=russyn — пример первичного издания и условий; проверки для других ID выполняются отдельно.
- Berean: https://berean.bible/licensing.htm — специальное заявление о текстах Berean Bible; не универсальная лицензия всех материалов сайта.

Web-страницы/контракты были прочитаны. Прямое получение полных файлов из среды исполнения не работало из-за DNS. Это не утверждение, что сами сайты недоступны на вашем VPS. Сохранённые тесты имитируют сетевые ответы по документированным структурам и обозначены как synthetic. Никакие тестовые слова не выдаются за текст Писания.

На VPS загрузчик проверяет конкретные полученные файлы, хранит сырые байты и хеш, сопоставляет каталоги с содержимым. BibleNLP commit разрешается/фиксируется на запуск; для native-источников сохраняются реальные URL, SHA и опубликованная метаинформация. Семантический sha ресурса не выдаётся за SHA-256 сырых байтов. Расхождения считаются ошибкой, не исправляются предположением.

Лицензионное решение хранится вместе с его доказательствами. Программная MIT-лицензия GitHub-репозитория не является разрешением на каждый включённый текст. Для сомнительных редакций нужна отдельная проверка, автоматического обхода нет.
