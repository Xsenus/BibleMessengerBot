# Проверка источника переводов

Релиз использует курируемый репозиторий `BibleNLP/ebible`, сформированный из
публикаций eBible.org. На 2026-09-21 ветка `main` была проверена на commit
`c531ff2da02843ded6d09afbe29a197ab844981f`.

В upstream подтверждены, среди прочих:

- `russyn` — русский Синодальный перевод, Public Domain;
- `ukr1871` — Новый Завет П. Кулиша, Public Domain;
- `eng-web` — World English Bible, Public Domain;
- `spaRV1909` — Reina-Valera 1909, Public Domain.

Это не фиксированный закрытый список. При установке импортёр читает актуальный
каталог, применяет строгую лицензионную политику и записывает SHA-256 каждого
реально загруженного файла. Если лицензия стала неизвестной или ограниченной,
редакция автоматически не попадает в базу.

Снимок проверки хранится в `data/source_snapshot.json`.
