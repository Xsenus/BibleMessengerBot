## Включённые каталоги UI

ar — العربية, bn — বাংলা, de — Deutsch, en — English, es — Español, fa — فارسی, fr — Français, he — עברית, hi — हिन्दी, id — Bahasa Indonesia, it — Italiano, ja — 日本語, ko — 한국어, nl — Nederlands, pl — Polski, pt — Português, ru — Русский, sw — Kiswahili, ta — தமிழ், tr — Türkçe, uk — Українська, ur — اردو, vi — Tiếng Việt, zh — 中文

Кантонский (`yue`) использует китайский интерфейс `zh`, а не отдельную кантонскую вычитку. Библейский иврит сопоставляется с интерфейсом `he`; это не обещание полного Нового Завета на библейском иврите. Предпочтительный ID редакции — подсказка ранжирования, не подтверждённый файл/лицензия.

Независимая языковая вычитка UI не проведена. Русский/английский имеют названия книг; другие языки используют USFM-коды.
