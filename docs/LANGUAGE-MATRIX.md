# Языковая модель

Три независимых понятия: язык UI, язык библейского текста и конкретная редакция. Все сохраняются для назначения: личного чата, группы, канала/темы. Изменение одного назначения не меняет остальные. Список языков Bible corpus формируется из БД, а не из заранее обещанных языков; меню разбито на страницы по 36 элементов.

В репозитории 24 UI-каталога: ar, bn, de, en, es, fa, fr, he, hi, id, it, ja, ko, nl, pl, pt, ru, sw, ta, tr, uk, ur, vi, zh. Это не все языки мира; независимой вычитки носителями не было. Команды, коды источников и диагностические машинные статусы остаются техническими идентификаторами.

getBible и HelloAO могут использовать другие ISO-коды, чем BibleNLP. При импорте сохраняется код источника; макроязык, диалект и древняя разновидность не сливаются. Соответствия макроязыков поддерживаются для фильтра импорта и выбора UI. Для однозначного выбора Библии используйте конкретную запись меню или /translation source:id. Наиболее обычные /language ru и /language en поддерживаются.

Для книги используется имя конкретного издания, если источник его предоставил; иначе локализованное имя существующего справочника (русский/английский) либо код USFM. Нет скрытого машинного перевода Библии. Название редакции, держатель прав и лицензионные сведения сохраняют исходное написание.

`/language` выбирает язык Библии и подходящий UI при его наличии; `/ui` меняет только UI. Точные команды: [TELEGRAM_SETUP.md](TELEGRAM_SETUP.md).
