# База данных 1.3.0

Используется прежняя PostgreSQL-схема. `schema.sql` и `002_hardening.sql` не изменены; миграции применяются последовательно с сохранением SHA-256. `003_multisource.sql` добавляет:

- `translations.content_sha256` — содержательная контрольная сумма пронумерованных строк;
- `translations.numbering_system` — пространство нумерации, индекс content по языку;
- `translation_sources` — source_slug + source_translation_id, ссылка на основную запись, исходный URL/SHA, ревизия, лицензия/решение/метаданные и время проверки;
- `translation_book_names` — собственные имена книг конкретного издания.

Основные существующие таблицы: languages, translations, books, book_names, verses, translation_chapters, telegram_users, telegram_chats, subscriptions, reading_progress, chat_reading_progress, delivery_log, import_runs, operator_events. `verses` хранит главу, стих, текст, продолжения диапазона, verse_end, исходную строку и плотный ordinal для эффективного чтения. Полнота и отчёт аудита записаны в translations. Главы имеют отдельный последовательный индекс.

Издания уникальны по паре source_name/source_translation_id. Внешний `source:id` разрешается также через alias; неоднозначный простой ID не выбирается случайно. Нельзя считать одинаковыми тексты из разных пространств нумерации только по названиям.

Запись одного издания: транзакция → проверка прав → подготовка метаданных → COPY строк порциями → построение chapter index → сверка содержательной суммы непосредственно по PostgreSQL → запись provenance → commit. Ошибка в любом пункте откатывает издание. Полный аудит повторно сравнивает физические строки и хеш для новых записей 1.3.0.

Операторские настройки и уже выбранные издания не очищаются загрузчиком. Автозамена изменённого текста заблокирована; явная замена ограничена неиспользуемыми изданиями. Старые записи без нового content_sha256 продолжают проходить прежний физический аудит, а хеш добавляется при проверенном повторном импорте.

Дамп других проектов не исполняется. Готовой наполненной БД в архиве нет. Реальное выполнение SQL-тестов в среде подготовки пропущено: отсутствуют PostgreSQL/asyncpg. Тесты для реального сервера включены в tests/test_postgres_integration.py и вызываются установщиком.
