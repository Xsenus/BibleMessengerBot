## Минимальный регламент

| Когда | Что |
|---|---|
| Раз в сутки | Автоматическая копия БД; проверьте `docker compose ps` |
| Раз в неделю | Панель → «Состояние», «Доставки»; проверить оповещения |
| Перед обновлением | Копия БД, затем `update.sh` |
| После обновления | `docker compose ps`, проверка `/start`, панель |
