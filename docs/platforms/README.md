# Платформы

Бот работает в Telegram, MAX и ВКонтакте на одном корпусе Библии и одной базе данных. Аккаунты и настройки каждой платформы разделены: одинаковые числовые идентификаторы на разных платформах не объединяются.

| | Telegram | MAX | ВКонтакте |
|---|---|---|---|
| Как бот получает сообщения | long polling, домен не нужен | вебхук, нужен HTTPS (порт 443) | Long Poll, домен не нужен |
| Профиль Compose | по умолчанию | `max` | `vk` |
| Токен | `BOT_TOKEN` | `MAX_BOT_TOKEN` | `VK_BOT_TOKEN`, `VK_GROUP_ID` |
| Форматирование | HTML | HTML-подобная разметка | обычный текст, ссылки в скобках |
| Кнопки | inline + нижняя клавиатура | inline + постоянная | inline (до 6 рядов, 10 кнопок) + клавиатура |
| Картинки и озвучка | да | да | да (озвучка вложением) |
| Платежи | Stars, ЮKassa | ЮKassa | нет |
| Каналы/группы | да | да | беседы и сообщество |

Для каждой платформы есть подробная инструкция:

- [Telegram](telegram.md) — настройка, группы и каналы, права, команды управления.
- [MAX](max.md), [HTTPS для MAX](max-https.md), [платежи в MAX](max-payments.md).
- [ВКонтакте](vk.md) — ключ сообщества, Long Poll, права, особенности.

## Что общее

- **Администраторы** назначаются кодом-приглашением (`/claim КОД`) на любой платформе — [как](../admin/README.md#как-назначить-администратора).
- **Объявления, рассылки и источники** работают для всех платформ сразу; аудиторию можно ограничить платформой.
- **Очередь доставки** общая: ограничения скорости и повторные попытки учитывают особенности каждого мессенджера.

## Чек-лист подключения новой платформы

1. Получите токен и сохраните его в `.env`.
2. Запустите службу профилем Compose.
3. Отправьте боту `/start` и проверьте ответ.
4. Станьте администратором: `/claim КОД`.
5. Проверьте в панели → «Состояние», что служба шлёт сигнал жизни.
