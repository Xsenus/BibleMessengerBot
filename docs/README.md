# Документация BibleMessengerBot

Выберите, кто вы — и откройте нужный раздел.

| Я… | Что открыть |
|---|---|
| **читатель**: хочу пользоваться ботом | [Руководство пользователя](user-guide/README.md) |
| **владелец**: хочу установить и запустить бота | [С чего начать](getting-started/README.md) → [Быстрый старт](getting-started/quick-start.md) |
| **администратор**: рассылаю объявления, слежу за каналами, настраиваю бота | [Руководство администратора](admin/README.md) |
| подключаю **Telegram, MAX или ВКонтакте** | [Платформы](platforms/README.md) |
| отвечаю за **сервер**: резервные копии, мониторинг, обновления | [Эксплуатация](operations/README.md) |
| ищу **справочник**: команды, переменные `.env`, таблицы БД, архитектура | [Справочник](reference/README.md) |
| хочу понять, **как устроена** конкретная функция | [Возможности](features/README.md) |
| **разработчик**: как всё устроено, как добавить мессенджер или генератор | [Для разработчиков](development/README.md) |

## Карта каталогов

```
docs/
├── getting-started/   установка и первый запуск
├── user-guide/        как пользоваться ботом (для читателей)
├── admin/             управление ботом: панель, объявления, источники, видео, генераторы картинок
├── platforms/         Telegram, MAX, ВКонтакте
├── features/          как работают чтения, переводы, озвучка, иллюстрации, расписания
├── operations/        эксплуатация, мониторинг, копии, безопасность, диагностика
├── development/       устройство систем, добавление мессенджеров и генераторов
├── reference/         команды, настройки, база данных, архитектура, ограничения
└── history/           отчёты и заметки прошлых выпусков
```

Журнал изменений — [CHANGELOG.md](../CHANGELOG.md). Правила для разработчиков — [CONTRIBUTING.md](../CONTRIBUTING.md). Безопасность — [SECURITY.md](../SECURITY.md).
