# BibleMessengerBot 1.2.0

Telegram-бот: отдельные настройки личных чатов, групп, каналов и темы форума, чтение по порядку, стих дня, тематические подборки и планы чтения. Это продолжение переданного проекта 1.1.0, а не пересозданный проект с вымышленной историей.

## Статус этой поставки — прочитать до установки

**Проверен исходный код и офлайн-сценарии. Это не подтверждённый запуск на живом VPS.** В среде сборки нет aiogram, asyncpg, PostgreSQL и Docker; получить их и полные тексты Библии из сети здесь не удалось. Автоматические тесты, которые требуют этих компонентов, помечены как пропущенные. Точное число, причины и команды — в `RELEASE-AUDIT.md`, `RELEASE-AUDIT.json`, `evidence/`.

**Архив не содержит загруженной Библии, готового дампа PostgreSQL или подтверждённых 56 языков текста.** Он содержит рабочий код импортёра и проверки, схему БД и настройки 56 целевых языков. На VPS установщик должен скачать разрешённые издания, реально импортировать их и проверить физические строки. До успешных проверок бот не запускается. Недоступность источника, отсутствие разрешённого полного издания или ошибка интеграции остановят установку, а не будут скрыты.

Язык интерфейса подготовлен для **24 языков**, не для всех 56. Каталоги переведены при разработке и не вычитаны независимыми носителями. Для названий книг есть русские и английские подписи; в остальных языках используются стандартные коды книг USFM, а не выдуманный перевод. См. `docs/LANGUAGE-MATRIX.md` и `docs/LIMITATIONS.md`.

## Установка на Ubuntu/Debian VPS

Нужны доступ root/sudo и исходящий доступ к репозиториям пакетов, Docker, GitHub и Telegram. Домен, публичный HTTP-порт и ключ ИИ не нужны: используется long polling. Параметры сервера не измерялись нагрузочными тестами; объём диска зависит от числа реально импортированных изданий.

```bash
sudo apt update
sudo apt install -y unzip
unzip BibleMessengerBot-1.2.0-ALL-IN-ONE.zip
cd BibleMessengerBot-1.2.0
sudo bash install.sh
```

При новой установке скрипт запрашивает токен бота, создаёт `.env` и секреты, собирает образ, запускает тесты с реальными установленными зависимостями и временной БД PostgreSQL, применяет миграции, импортирует корпус, проверяет БД и только затем запускает службы. Результаты на сервере: `runtime-evidence/`. После запуска отправьте боту `/start`, затем показанную установщиком команду `/claim ...` **в личном чате**. Код владельца не следует публиковать.

Повторный запуск сохраняет `.env` и пароли, делает резервную копию работающей БД и останавливает службы перед изменением схемы/корпуса. Для обновления с 1.1.0 сначала скопируйте исходный `.env` в каталог новой версии на том же Docker-хосте. Не удаляйте старый том и не выполняйте `docker compose down -v`.

## Отдельный язык для каждого места публикации

Личный чат: `/settings`. Канал: добавьте бота администратором с правом публикации, затем управляйте каналом из личного чата от своего реального аккаунта администратора:

```text
/settings @your_channel
/language en @your_channel
/subscribe verse 09:00 Europe/Amsterdam @your_channel
```

Другой канал может одновременно работать на русском:

```text
/language ru @another_channel
/subscribe sequential 08:00 Europe/Moscow @another_channel
```

`/language` выбирает язык текста и, когда он поддерживается, язык меню. Конкретное издание выбирается через `/translations` и `/translation SOURCE_ID`. `/ui en @your_channel` меняет только интерфейс. Изменение применяется к действующим подпискам этого чата, но не к другим чатам. Если разрешённого импортированного текста нет, выводится явная ошибка — русское издание молча не подставляется.

Меню команд Telegram привязано к языку клиента Telegram; сообщения и кнопки самого бота — к настройке конкретного назначения. Машинные имена команд, планов, тем и идентификаторы изданий остаются стабильными независимо от языка. Подробности и примеры: `docs/TELEGRAM_SETUP.md`.

## Что входит

Python / aiogram, PostgreSQL, отдельный worker, read-only административная страница FastAPI, Docker Compose, миграции, установщик, резервное копирование/восстановление, 24 каталога интерфейса, тесты, отчёты и Git bundle. **Redis, Alembic, нейросетевая генерация стихов, inline-режим и церковный календарь в этой версии не используются.**

Доставка сохраняет неизменный текст и подтверждение каждого фрагмента. Сбой после отправки, но до получения подтверждения может потребовать решения администратора; обещания «никогда не будет дублей» здесь нет. Порядок действий — в `docs/OPERATIONS.md`.
