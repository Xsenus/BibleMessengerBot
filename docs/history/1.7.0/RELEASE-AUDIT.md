## Что изменилось

Новые автоматические чтения содержат законченный стих или связный отрывок с полным диапазоном и выделенными номерами **[N]**. Для Синодального перевода используется каталог 181 чтения; все отрывки сверены с реальным корпусом. Фрагмент перечня из 1 Паралипоменон 24:13 отклонён. Для остальных изданий проверены пять выборок на каждое из 14 изданий; текст и координаты принадлежат выбранному источнику. Явно запрошенный адрес `/read` или `/search` сохраняет точные границы.

Текст приходит сразу без уведомления об очереди генерации. Готовая картинка добавляется редактированием исходной карточки. Отдельного продолжения нет. Сохранённые ID сообщений, полный текст и хеши каждого стиха защищают повторную доставку и смену исходного текста. Повтор редактирования после неопределённого сетевого результата безопасен; удалённая карточка не заменяется новой.
