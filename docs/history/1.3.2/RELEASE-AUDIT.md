# Проверка выпуска 1.3.2

22 сентября 2026. Система разовой поддержки в Telegram Stars развёрнута на VPS.

- Linux, Python 3.12 и PostgreSQL 16: **581 passed, 0 failed, 0 skipped**, 27,34 с. PostgreSQL-тесты выполнялись в отдельных временных БД; Telegram в тестах моделируется.
- Windows: **538 passed, 43 skipped**. Пропущены 35 тестов PostgreSQL и 8 POSIX-сценариев; все они отдельно выполнены на VPS.
- [CI проверенного кода](https://github.com/Xsenus/BibleMessengerBot/actions/runs/35717226589) завершился успешно.
- Реальный Telegram API принял создание ссылки на счёт XTR с одной ценой и пустым provider_token. Ссылка не публиковалась, тестовый заказ откатан; счёт никому не отправлялся.
- Через API подтверждены 18 команд, включая `/donate` и `/paysupport`; методы баланса и истории Stars отвечают. Обработчик pre-checkout включён в polling.
- Миграция `004` применена. Повторы, конкурентные платежи, неверные реквизиты, просроченные счета, возвраты и восстановление журнала проверены автоматическими тестами.
- Все четыре службы здоровы. Перед обновлением создана резервная копия; аудит существующего корпуса выполнен повторно без загрузки Библии.
- Код и документация опубликованы; секреты не добавлялись. Пакеты и сетевые границы не изменялись относительно 1.3.1.

**Реальная оплата и реальный возврат Stars не выполнялись.** Поэтому автоматические проверки и принятие счёта API не выдаются за завершённую платёжную транзакцию. Просмотр и ответы на `/paysupport` выполняет владелец через серверный CLI; автоматического уведомления владельца нет.
