## VPS и Telegram

- Миграция 011 → 012 применена. Все прежние строки 13 таблиц, включая 414 980 стихов, переводы, пользователей/чаты, картинки, попытки, цели, историю, подписки и прогресс, сохранились по каноническим SHA-256.
- Перед обновлением создана зашифрованная копия БД; загрузка в S3 проверена. Штатный backup timer активен. Новое полное восстановление не выполнялось.
- Все пять служб healthy. 14 изданий, 12 языков; PostgreSQL остаётся внутренним сервисом Docker.
- Telegram подтвердил изменение существующей карточки владельца на английский и обратно, с сохранённой фотографией и InlineKeyboard. Подтверждена прокрутка списка языков. Для этого отрывка доступны 11 языков на двух страницах. Исходный язык и первая страница восстановлены.

Исторические сообщения массово не изменяются. Для групп/каналов проверены программные контракты прав; живой тест в чужих группах не проводился. Адреса используются по нумерации самих изданий, автоматического сопоставления разных традиций нумерации нет. Это переключение сохранённых библейских текстов, не машинный перевод.
