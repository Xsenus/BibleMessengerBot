# Исторические материалы

Файлы этого каталога описывают переданные версии 1.1.0, 1.2.0 и 1.3.0. Их результаты относятся только к исходному коду и окружению соответствующей поставки. Они не подтверждают текущие тесты, состояние VPS или фактический набор корпуса.

| Версия | Материалы |
|---|---|
| 1.1.0 | [Исходный отчёт](RELEASE-AUDIT.md) и соседний JSON. |
| 1.2.0 | [Отчёт](1.2.0/RELEASE-AUDIT.md), README, notices и `evidence/` соответствующего каталога. |
| 1.3.0 | [Отчёт](1.3.0/RELEASE-AUDIT.md), [JSON](1.3.0/RELEASE-AUDIT.json) и полный исходный `evidence/`. |

Актуальные руководства находятся в родительском каталоге `docs/`. Проверки текущей подготовки и их границы: [VALIDATION.md](../VALIDATION.md). История изменений: [CHANGELOG.md](../../CHANGELOG.md).
