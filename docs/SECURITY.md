# Безопасность

- `.env` создаётся с правами `600`.
- Токен бота и пароли не входят в архив.
- Панель по умолчанию привязана к `127.0.0.1` и открывается через SSH-туннель.
- PostgreSQL не публикует порт на хост.
- Изменение групповых настроек требует статуса администратора Telegram.
- Подключение канала требует административных прав пользователя и бота.
- Код владельца применяется только в личном чате и только для первого владельца.
- SQL-запросы используют параметры; пользовательский текст не вставляется в SQL.
- HTML Telegram экранируется.
- Импорт ограничивает размер файлов, использует таймауты, SHA-256 и транзакции.
- Неизвестные и ограничительные лицензии выключены по умолчанию.

После `/claim` рекомендуется заменить `OWNER_CLAIM_CODE` в `.env` и
перезапустить bot. При утечке токена отзовите его через `@BotFather`, замените
`BOT_TOKEN` и выполните:

```bash
docker compose up -d --force-recreate bot worker
```
