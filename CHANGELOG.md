# История изменений

## 1.3.2 — 2026-09-22

- Добавлена разовая добровольная поддержка проекта через Telegram Stars: `/donate`, суммы от 1 до 2500, готовые кнопки и `⭐ Поддержать` в личной клавиатуре. Чтение и остальные функции остаются бесплатными.
- Добавлены история собственных платежей `/donations`, условия `/terms` и обращения `/paysupport`; заявки сохраняются в БД и требуют ручного рассмотрения оператором.
- Миграция `004` добавляет платёжный журнал и обращения. Счёт связан с пользователем/суммой, checkout проверяет состояние и срок, повторные уведомления платежа учитываются без дублирования.
- Перед созданием счёта пользователь явно принимает показанные условия; фоновая сверка транзакций Telegram дополняет обработку подтверждений оплаты и возвратов для известных локальных заказов.
- Добавлены операторские команды просмотра платежей/обращений/баланса, сверки транзакций, возврата через Telegram, ответа пользователю из файла и закрытия рассмотренной заявки. Неоднозначная отправка ответа не повторяется автоматически. Подробности — [DONATIONS.md](docs/DONATIONS.md).
- Реальная платёжная транзакция и реальный возврат Stars при подготовке не выполнялись; результаты тестов фиксируются отдельно после проверки версии.

## 1.3.1 — 2026-09-22

Доработка перед публичной публикацией и настоящим развёртыванием:

- Исправлена поддержка дополнительных книг getBible по проверенному соответствию издателя; Синодальный перевод сохраняется целиком с 78 книгами.
- Для getBible проверяется publisher SHA-1 сырого файла, отдельно от локального SHA-256 и содержательного хеша.
- Добавлена совместимая с Windows блокировка CLI импорта; установочные Bash-сценарии остаются предназначенными для Linux.
- Уточнены ограничения ресурсов Docker, остановка процессов и воспроизводимость Linux-зависимостей через `constraints-linux.txt`.
- Восстановление по умолчанию оставляет службы остановленными для согласования очереди с Telegram; запуск возможен явным `--start-services`.
- Добавлен `verify_backup.sh`: восстановление в отдельную временную БД и аудит без замены действующей БД. Предусмотрен ежедневный systemd backup timer.
- Добавлен CI с Python 3.12 и настоящим PostgreSQL 16; документация обновлена для публичного Git-репозитория, конфигурации, эксплуатации, участия в разработке и приватного сообщения об уязвимостях.
- Личный `/start` получил короткое приветствие и постоянную клавиатуру из шести действий; `/menu`, `/search` и `/time` дают подсказки, RU/EN-справка упрощена для первого использования.
- Добавлено автоматическое оформление имени, описаний, меню и аватара; собственные изображения и точные prompts сохранены в `assets/brand/`. Фоновое обновление по хешу не блокирует Telegram polling.
- Названия переводов в интерфейсе стали читабельными; для Public Domain/CC0 подпись отрывка сокращена до названия издания, а полные сведения доступны через `/license`. Обязательная атрибуция других лицензий и исходные метаданные сохранены.
- Реально скачаны и импортированы `getbible:synodal` и `getbible:web`, 68 193 строки стихов; подробные проверки и ограничения приведены в [VALIDATION.md](docs/VALIDATION.md).

## 1.3.0 — 2026-09-22

Добавлены адаптеры BibleNLP/eBible, getBible и HelloAO, проверка лицензий, кэш с докачкой/лимитами/хешами, транзакционное сохранение, alias источников, содержательные хеши и названия книг издания. Появились CLI `discover/download/import/status/config`, сценарий `fill_database.sh` и постраничный выбор языка. Подробности исходной поставки — [CHANGES-1.3.0.md](docs/CHANGES-1.3.0.md).

Добавлены 24 интерфейса, настройки каждого назначения, проверки корпуса/диапазонов, планы чтения, пофрагментная очередь с ручным разрешением неопределённой доставки, DST, авторизация, миграция `002`, блокировка обслуживания и административная диагностика только для чтения.
