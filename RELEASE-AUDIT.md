# Проверка выпуска 1.10.1 — 8 октября 2026

Суточные лимиты разделены: по 10 API-попыток для каждого провайдера; месячный резерв $10 остаётся общим. Провайдер с исчерпанным лимитом пропускается без нового запроса. При полном исчерпании сервисов задание сохраняется до следующих UTC-суток. Отказы, неизвестные ответы и смена ключа не обнуляют счётчики. [Поведение и подключение](docs/IMAGE_PROVIDERS.md).

Проверенный код: `bbb492d693118c1c87bc6e74847adeef982867a4`. [CI](https://github.com/Xsenus/BibleMessengerBot/actions/runs/37744469278): **725 passed, 0 skipped, 109.35 с**. На VPS в отдельных одноразовых PostgreSQL-базах: **49 passed, 35.80 с** для лимитов/истории/глав/постоянных карточек; после доработки загрузчика **45 passed, 16.61 с** для окончательных адаптеров и маршрутизатора. Telegram и платные API в этих тестах моделируются. На Windows: **619 passed, 106 skipped, 10.83 с**; пропущенные проверки требуют PostgreSQL. Ruff новых адаптеров, маршрутизатора и их тестов прошёл.

Проверены независимые суточные счётчики, конкурентный выбор разных сервисов при последней свободной попытке, ожидание следующего дня, сброс по UTC, сохранение лимита при смене ключа, общий месячный резерв, безопасное переключение и обновление всех исходных карточек. PNG больше 5 MiB обрабатывается из одного готового ответа: проверка до 20 MiB/9 млн пикселей и JPEG до 5 MiB с сохранением разрешения, без повторной платной генерации.

## Живая проверка на VPS

- Все пять служб healthy; 14 изданий, 12 языков, схема 011 без новых миграций.
- OpenAI исчерпал 10 суточных попыток; бот автоматически выбрал Ideogram. Выполнены три успешные генерации Ideogram, обновлены все три ожидавшие подтверждённые исходные карточки, включая главу. Telegram подтвердил редактирование каждой. Готовых изображений стало 14.
- На момент проверки: OpenAI 10/10, Ideogram 4/10; общий внутренний месячный резерв $1.40/$10. Это снимок счётчиков, не фактический счёт провайдеров.
- Одна попытка Ideogram дала необработанный ответ до доработки загрузчика; её резерв сохранён как неопределённый, повторного платного запроса тому же провайдеру/ключу для этого задания нет. Точную причину первого ответа без сохранённого тела установить нельзя. Старое неопределённое задание OpenAI не возобновлялось.
- Зашифрованная копия БД перед окончательным обновлением проверена загрузкой из S3 и SHA-256. Новое полное восстановление БД не выполнялось.

OpenAI и Ideogram подключены. Gemini, BFL и Stability без действующих ключей пропускаются; их реальное качество/баланс не проверены. Исходный текст не ждёт API; ожидание изображения не гарантирует успешную генерацию при любом отказе или исчерпанном месячном резерве.
